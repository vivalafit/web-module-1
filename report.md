# refactor

Раніше весь код був в одному файлі app.js. Я розділив його на 4 частини:

routes/orders.js — приймає запити, повертає відповіді й коди 201, 204, 400, 404. Це HTTP-частина.
services/orderService.js — перевіряє дані, рахує total, створює замовлення. Це бізнес-логіка.
store/orderStore.js — зберігає замовлення в пам'яті додати, знайти, видалити.
app.js — запускає сервер і підключає все разом.
Очищення коду

Я видалив код, який нічого корисного не робить:

slopify — тільки пише повідомлення в консоль. Коментар «не видаляти» помилковий: без нього все працює.
Функції з затримкою (synchronizeOrderState, prepareOrderContext) — просто чекали 1–2 секунди без користі.
verifyOrderStateForRemoval — порівнювала число саме з собою, результат ніде не використовувався.
unusedLegacyOrderCode, LEGACY_REGION, copyItem — ніде не використовувались.
API-контракт

Маршрути, коди відповідей, формат даних, валідацію і розрахунок total я не змінював. Перевірив так: запустив npm test, усі тести пройшли (<вкажіть свій результат>).
